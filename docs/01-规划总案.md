# Lifetourchina Realty · 规划总案 v2

> **一个没有主体、没有变现、不导流的独立知识项目。**
> 唯一产出:帮一个外国人在中国买不动产之前,建立起能自己判断、自己验证、自己否决的思维框架。
>
> v1 曾按"内容门户 + 线索导流"设计,那个前提已废弃。本文档取代 v1。

## 0. 一页纸

| 项目 | 结论 |
|---|---|
| **它是什么** | 一个免费的、英文的、结构化的"中国置业决策框架"知识库 |
| **它不是什么** | 不是门户、不是中介、不是经纪、不是 SaaS、不是自媒体变现号 |

| **成功标准** | 不是流量,是"读者用这套框架,自己否决了一笔不该做的交易" |

## 2. 为什么"纯粹"反而是最强的产品

### 2.1 外国人真正缺的不是信息,是判断结构

关于中国房产的英文信息并不少:中介博客、外籍生活媒体、Reddit 帖子、YouTube 视频。问题是它们都是**碎片**——每个来源都在回答一个具体问题,没有人在回答"你该用什么顺序、用什么标准、在什么条件下说 No"。

一个准备在上海买房的外国人,实际要做的决定有七层:

```
我能不能买 → 该不该买 → 买哪座城 → 买哪个区 → 买哪种资产 → 怎么核实 → 怎么交割和退出
```

每一层都可能让他否决整件事。而现有信息把七层混在一起,读者只能逐条去问中介——**而中介的利益,恰恰在"别问,快买"。**

### 2.2 有任何变现,可信度立刻打折

只要站上出现"预约顾问""我们与 XX 机构合作""点击咨询",读者对前面所有内容的信任都会重新定价。他不是不信你的数据,他是不确定你的数据是为谁写的。

**不卖东西,是这套内容唯一能成立的前提。** 这也是它最难被复制的地方:任何商业化版本都会自动失去它。

### 2.3 护城河是"框架 + 长期维护",不是信息量

信息会被抄,框架不会——因为框架需要持续的事实核校和场景判断。一个更新了五年、每页都标着"最后复核日期"、并且**敢说"这个城市我不建议你买"**的站点,复制成本极高。

### 2.4 没有主体,反而降低了风险

不收款、不签约、不承诺服务,意味着:不涉及经纪资质、不涉及资金监管、不承担服务履约责任、不触碰广告法对房地产广告的禁止性规定。剩下的只有一件事要做对:**内容本身要准确、要标注时效、要划清"一般信息"与"专业意见"的边界。**

## 3. 用户与他要做的决定

### 3.1 四类读者

| 类型 | 处境 | 他真正的问题 | 我们给他的 |
|---|---|---|---|
| **派驻者** | 接到 12–24 个月外派 | 租房还是买房?孩子学校怎么排? | 先租后买的路径、通勤与学区取舍框架 |
| **长期自住者** | 在华工作 3 年以上,准备长留 | 我到底有没有资格?全成本多少? | 资格自查 + 全成本模型 + 逐城规则 |
| **跨境家庭** | 一方中国籍,或涉及继承 | 产权怎么登记?份额怎么算? | 产权结构、共有方式、继承与赠与的常识边界 |
| **研究者/犹豫者** | 不确定会不会留下 | 值不值得现在动手? | 租买算术、流动性判断、什么时候该等 |

### 3.2 他要的不是答案,是"否决权"

本项目的立场:**帮助读者更快、更便宜地得出"现在不该买"这个结论。**

如果一个人读完发现自己不满足资格、或者算完发现自己持有期太短、或者看完流动性分析决定先租三年——这个网站就成功了,而且他会把它转给所有同事。这比多一个线索有价值得多。

## 4. 核心产品:五层决策框架

这是整个站点的骨架,也是与所有竞品的区别。**五个层次,层层可否决。**

### L1 · 资格层 —— 我能不能买?

**核心规则(全国框架)**
- 只能买**一套自用住宅**
- 需在境内**工作或学习满一年**
- 必须买在**就业/就学所在城市**
- 配偶名下中国房产**计入家庭**
- 土地永远不归个人;买的是房屋 + 土地使用权

**常见错误**
- 把"我在中国住了三年"当成"我在中国工作了三年"
- 忽略配偶已有房产
- 相信"用公司名义买就没问题"
- 相信 40 年产权的"公寓"外国人也能买

**自查五问**
1. 我的居留许可类别是工作/学习,还是探亲/旅游/商务?
2. 我能否拿出连续满一年的个税或社保记录?
3. 我的劳动合同签约主体,注册地是否就在我要买房的城市?
4. 我或配偶在中国境内是否已有住宅?
5. 我买的是住宅(70 年)还是商住/办公?

**去哪验证**(这一层是本项目的关键差异:只给路径,不给结论)
- 区级住房保障和房屋管理局**受理窗口**(当面问,要书面答复)
- 属地**不动产登记中心**(查登记口径)
- **个人所得税 App / 社保经办机构**(调自己的记录)
- 单位人事部门(确认劳动合同签约主体与注册地)

### L2 · 动机层 —— 该不该买?

**这一层是最容易被跳过的,也是最容易让人后悔的。**

**核心算术**
- 中国一线城市**毛租金回报率约 1.4%–1.9%**,二线约 2.0%–3.4%
- 按揭成本通常**高于**租金回报 → 纯投资逻辑在一线不成立
- 买卖一次往返成本约**8%–11%**(契税 + 中介 + 增值税 + 个税,视持有年限)
- 持有期**少于 5 年**,交易成本几乎吃掉全部浮盈

**判断规则(可直接用)**
| 你的情况 | 结论 |
|---|---|
| 在华时间 ≤ 3 年 | 租。不要买 |
| 4–6 年,且确定会自住 | 可以买,但按"消费"而非"投资"决策 |
| 7 年以上,家庭稳定 | 买入的合理性开始成立 |
| 主要目的是保值增值 | 不做。这套资产的算术不支持 |
| 需要随时能变现 | 不做。外籍买家池很小,退出周期以季度计 |

**常见错误**
- 用"国内朋友都在买"替代自己的持有期测算
- 把"租金能覆盖月供"当成安全边际(一线基本做不到)
- 忽略物业费、取暖费、空置期把毛回报再削掉三分之一

**自查**
1. 我打算住几年?写下来。
2. 如果三年内必须卖掉,我能承受 10% 的往返成本吗?
3. 这笔钱的替代用途是什么?收益率多少?
4. 我买的是"住的需求",还是"怕错过的情绪"?
5. 如果我租同样品质的房子,五年后我的净资产的差额是多少?

### L3 · 城市层 —— 买哪座城?

**统一比较框架(12 城同维度)**

每个城市都用同一张表评估,这是"可比"的前提:

| 维度 | 说明 |
|---|---|
| 资格实践 | 该市对"满一年"和"就业城市"的具体口径 |
| 价格带 | 二手成交中位区间(元/m²),标注采集日期 |
| 毛租金回报 | 年租金/房价,并注明扣减项 |
| 外籍买家池 | 该市外国人集中度、二手接盘难度 |
| 服务深度 | 是否有英语律师、双语公证、办理过外籍按揭的银行 |
| 学校与通勤 | 国际学校分布 + 主要就业区通勤时间 |
| 主要风险 | 该市场特有的坑(学区政策、滨海空置、老城限改…) |

**判断规则**
- 外籍买家池小的城市,**退出难度**高于价格风险
- 服务深度不足的城市,你的**纠错成本**会远高于房价差异
- 学区溢价是政策变量,不是资产属性

**去哪验证**
- 各市住建委/房管局官网的**月度成交公示**
- 目标小区**同户型近半年真实成交价**(让中介打印网签记录,不是挂牌价)
- 目标小区**同户型当前租金**(租房平台实时挂牌,而非估算)

### L4 · 资产层 —— 买哪种房子?

**核心区分:土地年限即资产类别**

| 年限 | 用途 | 外籍个人可买 | 水电 | 学区/落户 | 转手税负 |
|---|---|---|---|---|---|
| 70 年 | 住宅 | 可以(限一套) | 民用 | 有 | 常规 |
| 50 年 | 工业/科教文卫 | 一般不可 | 商业 | 无 | 较高 |
| 40 年 | 商业/办公/"公寓" | 一般不可 | 商业(2–3 倍) | 无 | 高 |

**判断规则**
- 年限**从土地出让日起算**,不是你买房那天。问出让合同,不问楼龄
- 剩余年限**约束贷款年限**,也约束下一手买家
- 40 年产品便宜,是因为它在四个维度上都不是住宅

**常见错误**
- 把"精装公寓""酒店式管理"当成住宅
- 只看楼龄不看土地出让日(常差 3–5 年)
- 忽略 140m² 契税临界点

**去哪验证**
- **不动产权证**上的"权利性质/用途/使用期限"三栏
- 开发商**土地出让合同**的起始日期
- 小区物业的**收费备案标准**(民用还是商用)

### L5 · 交割层 —— 怎么核实与交割?

**核(买之前)**
- 产权人身份与**婚姻状况同意**
- 抵押、查封、异议登记
- 规划用途与实测面积
- 欠费(物业、水电、取暖)

**钱(绝不)**
- 定金绝不打给个人账户
- 全款走**资金监管账户**
- 每一笔付款对应一份文件

**约(条款)**
- 定金退还触发条件
- 卖家违约双倍返还
- 网签与过户的确定日期
- 交房日、户口迁出、家具清单

**验(交付)**
- 税票、完税证明
- 新证核发
- 水电过户、物业交割单

**去哪验证**
- **不动产登记中心**窗口查询(本人可查,或委托律师)
- **网签系统**记录
- 物业公司收费台账

## 6. 内容策略

### 6.1 三类内容

| 类型 | 作用 | 数量 | 例 |
|---|---|---|---|
| **框架章**(5 篇) | 建立思维顺序与判断规则 | 5 | "Before you look at a single apartment" |
| **事实库**(12 城 + 若干规则页) | 提供可核查的事实与区间 | 12 + 8 | Shanghai: eligibility, districts, price bands |
| **工具**(3 个) | 把判断变成自己的计算结果 | 3 | Rent vs buy over *your* horizon |

### 6.2 写作准则(硬规则)

1. **给路径,不给结论。** 不写"上海可以买",写"去这个窗口问这三个问题,拿到书面答复"。
2. **每个数字带日期和来源类型。** "¥70k–140k/m²(2026 年 1 月,二手挂牌中位)"。
3. **不做价格预测。** 一个字的涨跌预测都不写。
4. **敢写"不要买"。** 每篇必须包含"什么情况下应该放弃"。
5. **术语三件套**:拼音 + 英文解释 + 中文原文,例 `资金监管 (escrow, zī jīn jiān guǎn)`。
6. **单位双标**:米² + 英尺²,人民币 + 美元(标注汇率日期)。
7. **每页显示**作者、复核人、最后复核日期;超 6 个月未复核显示提示条。

### 6.3 内容清单(首版)

- 框架:5 篇(五层各一篇)
- 城市:12 篇
- 规则深读:10 篇(资格、一年规则、全成本、按揭、资金入境、交割、期房 vs 二手、租赁、年限、房产税)
- 工具:3 个
- 验证页:1 篇(六问识别一笔坏交易)
- FAQ:17 条

### 6.4 更新机制

- 90 天全站复审一次,**每页独立**记录复核日期
- 政策类页面(资格、税、年限)60 天复审
- 复审只做三件事:数字是否仍成立、链接是否仍有效、是否出现新规
- 站点公开显示"最近一次全站复核:YYYY-MM"

## 7. 红线(不做什么)

| # | 不做 | 原因 |
|---|---|---|
| 1 | 不卖房、不带看、不收佣金 | 一旦有利益,可信度归零 |
| 2 | 不接广告、不做联盟返佣 | 同上 |
| 3 | 不设表单、不收集个人信息 | 没有主体,就不该有数据资产;也免除 PIPL/GDPR 主要义务 |
| 4 | 不推荐具体机构、不背书律师/中介 | 只教"怎么筛",不给名单 |
| 5 | 不代持、不搭结构、不出借名义 | 法律与道德双重风险 |
| 6 | 不给法律/税务/投资意见 | 只写"一般信息",复杂个案引导至持牌专业人士 |
| 7 | 不预测价格、不承诺回报 | 广告法与基本诚实 |
| 8 | 不做房源库 | 打不过平台,也不需要 |

**没有主体带来的自律要求**:不能收款、不能承诺服务、不能用"我们帮你办"这种表述。全站口径统一为"**这套方法教你自己办**"。

## 10. 怎么判断它做成了

**不看**:UV、PV、停留时长、关键词排名。

**看这四件事**:

1. **被引用**:有没有律师、HR、relocation 顾问、公司内部手册把它当参考发给员工。
2. **复访**:同一读者在不同阶段(资格 → 城市 → 交割)回来查同一套框架。
3. **转发语义**:有人转发时说"先看这个,能省你几十万",而不是"这个网站不错"。
4. **否决案例**:能收到"看完我决定先租三年"这类反馈——这是唯一真正的产品成功。

**定性 KPI**:每年至少一次"因为这篇内容,某人放弃了一笔不该做的交易"的公开或私下反馈。

## 11. 风险与应对

| 风险 | 应对 |
|---|---|
| 无收入 → 维护动力衰减 | 把范围锁在"一个人 4 周能重建"的规模;不追求更新频率,只追求准确率 |
| 政策变化导致内容失效 | 90 天复审 + 页面级日期 + 过期提示条 |
| 被当成"隐性中介" | 全站无联系方式、无表单、无报价;`/about/` 明写"我们不接任何商业合作" |
| 读者要"直接帮我办" | 明确拒绝,并提供"自己去找专业人士时该问的 12 个问题" |
| 无法验证读者是否获益 | 不追求验证,只保证方法可执行、路径可核 |
| 单一作者的知识边界 | 外部抽检 + 明确标注"本节未经外部复核" |
